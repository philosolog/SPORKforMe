# SPORKforMe

> **This project is no longer working due to updates on the SPORK website.**

This is a project I made for scraping content from my high school's LMS, [SPORK](https://www.spork.tech/about-us), in advance, primarily for usage on my local computer or when I went on vacation and didn't have stable internet. It served its purpose well, but due to SPORK's site updates (UI restructuring around the time it was renamed to SPORKforYou), this scraper is now broken.

I'm keeping this repo up as an archive of my code from 2022.

## Features (Legacy)

- Compile course assignments from SPORKForAll.
- Download assets from each course tab.
